\section{Abstract}

\vspace{0.3cm}

\noindent
\textbf{Handwritten Digit Recognition} is one of the most important applications of \textbf{Artificial Intelligence}, \textbf{Machine Learning}, and \textbf{Computer Vision}. It is widely used in automation systems, banking applications, educational tools, postal systems, document digitization, and OCR-based technologies. The ability of machines to accurately understand handwritten content has become increasingly important for developing intelligent and efficient digital solutions.

\vspace{0.4cm}

\noindent
This project presents an advanced \textbf{Handwritten Digit Recognition System} using \textbf{Deep Learning} and \textbf{Optical Character Recognition (OCR)} capable of identifying both \textbf{single-digit} and \textbf{multi-digit handwritten inputs} with improved flexibility and prediction accuracy. Unlike traditional systems that mainly focus on standard numerical digits, the proposed system also supports \textbf{Roman numeral recognition} and handles complex handwritten patterns effectively.

\vspace{0.4cm}

\noindent
The system is developed using \textbf{Convolutional Neural Networks (CNNs)} along with \textbf{Tesseract OCR} for improved image scanning and text extraction. Various image preprocessing techniques such as grayscale conversion, thresholding, contour detection, noise removal, digit segmentation, and orientation correction are implemented to improve recognition quality for rotated, noisy, and irregular handwritten images.

\vspace{0.4cm}

\noindent
A major feature of the project is the \textbf{adaptive retraining mechanism}, where wrongly predicted samples are stored in a custom dataset and later used for additional model training. This allows the system to continuously improve its learning capability and prediction performance over time.

\vspace{0.4cm}

\noindent
To improve practical usability, a \textbf{Flask-based web application} has also been developed where users can upload handwritten digit images and instantly receive prediction results through a simple and interactive interface.

\vspace{0.4cm}

\noindent
Overall, the project demonstrates the practical implementation of \textbf{Artificial Intelligence}, \textbf{Deep Learning}, \textbf{OCR}, and image processing techniques in building an intelligent, scalable, and user-friendly handwritten digit recognition system suitable for real-world applications.

\section{Introduction}

\vspace{0.3cm}

\noindent
\textbf{Handwritten Digit Recognition} is an important application of \textbf{Artificial Intelligence}, \textbf{Machine Learning}, and \textbf{Computer Vision}. \vspace{0.3cm}

\noindent
In recent years, the demand for intelligent handwritten recognition systems has increased due to the growing use of automation and digital technologies. However, traditional handwritten recognition systems often face challenges while handling unclear handwriting, rotated images, multiple digits in a single image, noisy backgrounds, and irregular spacing between digits. These limitations reduce prediction accuracy and affect real-world implementation.

To overcome these challenges, this project introduces an advanced handwritten digit recognition system using \textbf{Deep Learning} and \textbf{Optical Character Recognition (OCR)} techniques. \item Supporting \textbf{Roman numeral identification}

\item Learning from wrongly predicted samples through \textbf{custom retraining}

\noindent
The project uses image preprocessing, digit segmentation, OCR-based extraction, and a \textbf{CNN-based prediction model} to improve recognition performance. \section{Problem Statement}

\vspace{0.3cm}

\noindent
Accurate recognition of handwritten digits remains a challenging task in the field of \textbf{Artificial Intelligence} and \textbf{Computer Vision} due to the large variations in human handwriting styles, image quality, spacing, alignment, and orientation. Handwritten inputs often contain unclear strokes, irregular patterns, noise, and inconsistent formatting, which make digit identification difficult for traditional recognition systems.

\vspace{0.3cm}

\noindent
Most existing handwritten digit recognition systems mainly focus on recognizing only \textbf{single numerical digits} under controlled conditions. These systems generally fail when:
\begin{itemize}
\item Multiple handwritten digits are present in a single image
\item Images are rotated, inverted, or poorly aligned
\item Digits contain irregular spacing or overlapping structures
\item Roman numeral representations are used
\item Noisy or low-quality handwritten images are provided
\end{itemize}

\vspace{0.3cm}

\noindent
Another major limitation in many recognition systems is the lack of adaptive learning. Once the model is trained, it usually cannot improve automatically from its previous mistakes, resulting in repeated prediction errors for difficult handwritten samples.

\vspace{0.3cm}

\noindent
To overcome these limitations, the problem addressed in this project is to design and develop an intelligent handwritten digit recognition system capable of:
\begin{itemize}
\item Detecting both \textbf{single-digit} and \textbf{multi-digit} handwritten inputs
\item Identifying \textbf{Roman numeral representations}
\item Handling rotated and irregular image alignments
\item Improving prediction accuracy using \textbf{OCR integration}
\item Supporting continuous retraining for better learning from mistakes
\item Providing a \textbf{user-friendly web interface} for real-time usage
\end{itemize}

\vspace{0.3cm}

\noindent
The proposed solution aims to build a more flexible, scalable, and intelligent recognition system by combining \textbf{Deep Learning}, \textbf{OCR}, image preprocessing, digit segmentation, and adaptive retraining techniques into a single integrated platform.

\section{Literature Review}

\vspace{0.3cm}

\noindent
Handwritten Digit Recognition has been an important research area in the fields of \textbf{Artificial Intelligence}, \textbf{Machine Learning}, and \textbf{Computer Vision} for several years. Earlier handwritten recognition systems mainly relied on traditional machine learning algorithms where manual feature extraction techniques were used before classification. These approaches required significant preprocessing efforts and often produced limited accuracy for complex handwritten patterns.

\vspace{0.3cm}

\noindent
With the advancement of \textbf{Deep Learning}, \textbf{Convolutional Neural Networks (CNNs)} became highly effective for image-based recognition tasks. CNN models automatically learn important image features such as edges, curves, shapes, and handwritten patterns directly from the dataset, resulting in significantly improved recognition accuracy and reduced manual intervention.

\vspace{0.3cm}

\noindent
Researchers have also explored the use of \textbf{Optical Character Recognition (OCR)} systems such as \textbf{Tesseract OCR} for extracting textual information from images. OCR technologies improved the capability of systems to convert image-based handwritten content into machine-readable formats and enhanced the preprocessing workflow before classification.

\vspace{0.3cm}

\noindent
Despite these advancements, many existing handwritten recognition systems still face several limitations while handling:
\begin{itemize}
\item Multiple handwritten digits in a single image
\item Rotated or inverted handwritten inputs
\item Irregular spacing and alignment between digits
\item Noisy and low-quality handwritten images
\item Mixed numeral formats such as Roman numerals
\end{itemize}

\vspace{0.3cm}

\noindent
Most traditional systems are also limited by fixed training datasets and do not support adaptive learning from previously misclassified samples. This reduces their ability to improve continuously when exposed to real-world handwritten variations.

\vspace{0.3cm}

\noindent
The proposed system addresses these limitations by integrating \textbf{Deep Learning}, \textbf{OCR}, image preprocessing, digit segmentation, and adaptive retraining techniques into a unified intelligent platform. The system is designed to provide improved flexibility, higher prediction accuracy, and better handling of complex handwritten digit recognition scenarios.

\subsection{OCR Integration}

\vspace{0.2cm}

\noindent
\textbf{Tesseract OCR} has been integrated into the system to improve image scanning and text extraction before prediction. OCR helps refine handwritten image inputs and enhances recognition performance, especially for unclear or complex handwritten content.

\subsection{Digit Segmentation}

\vspace{0.2cm}

\noindent
For recognizing multiple handwritten digits from a single image, contour detection and image segmentation techniques are used. Each digit is separated individually before being passed to the prediction model. This improves multi-digit recognition accuracy and helps handle irregular spacing between digits.

\vspace{0.4cm}

% ---------------- MODEL DEVELOPMENT ----------------

\subsection{Model Development}

\vspace{0.2cm}

\noindent
The prediction model is developed using \textbf{Convolutional Neural Networks (CNNs)}. CNN architecture automatically extracts important image features such as edges, curves, and handwritten patterns from the dataset. This helps achieve high recognition accuracy while reducing manual feature extraction efforts.

\vspace{0.4cm}

% ---------------- CUSTOM RETRAINING ----------------

\subsection{Custom Retraining}

\vspace{0.2cm}

\noindent
A custom retraining mechanism has been implemented to improve continuous model learning. Whenever the system predicts an incorrect output, the corresponding handwritten image is stored in a custom dataset and later used for additional model training. This helps improve future prediction accuracy and makes the system more adaptive.

A \textbf{Flask-based web application} has been developed to improve accessibility and practical usability of the system. Through the web interface, users can upload handwritten digit images and instantly receive prediction results directly in the browser in real time.

The implementation of contour-based segmentation also helped in accurately separating and recognizing multiple handwritten digits from a single image.

\vspace{0.3cm}

\noindent
Another important feature of the project is the implementation of a \textbf{custom retraining mechanism}, where wrongly predicted handwritten samples are stored and later used for additional model training. This enables the model to continuously improve its learning capability and enhance future prediction performance.

\vspace{0.3cm}

\noindent
The developed \textbf{Flask-based web application} further improved the usability and accessibility of the system by allowing users to upload handwritten images and receive prediction results instantly through a simple and interactive interface.

\vspace{0.3cm}

\noindent
Overall, the project demonstrates the effective integration of \textbf{Artificial Intelligence}, \textbf{Computer Vision}, \textbf{OCR}, and \textbf{Deep Learning} technologies in building a practical, scalable, and user-friendly handwritten digit recognition system suitable for real-world applications and intelligent automation systems.
